ASTROWORLD — QUICK START

1. Open index.html in your browser to test the site.
2. To publish free: create a GitHub account, create a public repository named astroworld, upload index.html to the repository root, then open Settings > Pages.
3. Choose Deploy from a branch, select main and /(root), then Save.
4. GitHub Pages will show your public URL.

This is a starter demo. It creates general reflective text, not a calculated Vedic Kundli. It does not calculate planetary positions, Lagna, Rasi, Nakshatra or Dasha. For accurate Vedic reports, integrate a verified ephemeris/astrology engine and timezone/location calculations. Birth details stay in the browser in this demo; there is no database or server.
